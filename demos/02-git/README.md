# Git / GitHub demos

Two live demos: first the basic Git workflow on your own machine, then collaboration on GitHub (including merge conflicts).

1. [Getting started with Git / GitHub](git-basics-demo.md): clone, status, add, commit, unstage, push, and pull.
2. [Collaboration with Git / GitHub](team-git-demo.md): work in pairs or threes on a shared repo to explore collaborative workflows.

Do them in that order. Use `~/ds2022-fall-26` for both, and do not clone inside another Git repository.

Setup (Git, GitHub account, Personal Access Token) is in [setup/git.md](../../setup/git.md).
